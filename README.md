# 記帳本

一個給自己用的記帳網頁 App。跟一般記帳 App 不同的地方是它以**先規劃、再花錢**為主軸：

1. 每個月先把薪水**分配到各個帳戶**（生活費、房租、儲蓄、投資…），實際轉完帳就打勾。
2. 指定其中一個帳戶當**零用錢來源**，App 自動算出**每天可以花多少**。
3. 首頁像熱量 App 一樣，一眼看到「今天還能花多少」。

## 功能

- **薪水分配** — 每月收入拆到各項目，逐筆勾選「已轉帳」，未分配金額即時提示。
  設定過一次之後，**之後每個月自動沿用**（打勾狀態會清空），改動才會存成該月專屬的
- **分配項目自己定義** — 名稱自己取（房貸、學貸、旅遊基金…），並指定類型：
  日常零用錢 / 固定支出 / 儲蓄 / 投資 / 其他。可在分配頁當場新增，點名稱即可改。
  清單會依類型分組並顯示各組小計
- **每日零用錢** — 由零用錢帳戶自動推算，也可以手動指定；支援**結餘累積**（今天沒花完，明天可以繼續花）
- **快速記帳** — 計算機式數字鍵盤，支援 `+` `−` 直接算（分帳、湊發票好用），自動帶入上次使用的分類
- **詳細說明與照片** — 每筆可寫多行說明（吃了什麼、在哪買的），並附上照片（發票、餐點）。
  照片會自動壓縮後存進 IndexedDB，明細列表直接顯示縮圖
- **明細** — 依日期分組、每日小計，可搜尋、篩選，點一下就能修改或刪除
- **統計** — 每日支出長條圖（標出超過額度的日子）、分類佔比排行、近 6 期比較
- **自訂** — 帳戶與分類都可以自己增刪改（圖示、顏色）
- **記帳週期** — 可設定每月起算日，發薪日不是 1 號也能對齊
- **深色模式** — 跟隨系統或手動切換
- **PWA** — 手機「加入主畫面」後就像原生 App，離線也能開

## 資料存在哪

資料存在**瀏覽器本機**，不會上傳到任何地方：

- 記錄、分類、帳戶、每月計畫 → `localStorage`
- 照片 → `IndexedDB`（一張手機照片好幾 MB，localStorage 全部只有 ~5MB 放不下）

這代表**手機和電腦各自是獨立的一本帳**。要搬資料請用「設定 → 資料備份 → 匯出備份 / 匯入備份」，
備份檔含照片，所以照片多的話檔案會偏大。設定頁也會顯示目前用掉多少空間。

清除瀏覽器資料會連記錄一起清掉，建議定期匯出備份。

> 之後若要做到手機／電腦自動同步，資料層（`src/lib/storage.ts`）已經抽象成 `StorageAdapter` 介面，
> 加一個雲端實作即可，UI 不用改。

## 開發

```bash
npm install
npm run dev      # 本機開發
npm run build    # 產出 dist/
npm run preview  # 預覽 build 結果
```

## 部署

推到 `main` 或任何 `claude/*` 分支就會自動經由 GitHub Actions 部署到 GitHub Pages。

第一次使用需要先到 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

網址會是 `https://<帳號>.github.io/accounting-book/`。

## 技術

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · 無執行期相依套件（圖表為手刻，不依賴圖表庫）
